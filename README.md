1) What is the difference between var, let, and const?
Solution:
Var - Function scope, can redeclare and reassign
let - Block scope, can not redeclare but can reassign
const - Block scope, can not redeclare or reassign.

2) What is the difference between map(), forEach(), and filter()? 
Solution:
map() - loop through each element of array and return a new array of same length.
forEach() - loop through each element of array and does not return a new array.
filter() - loop through each element of array and return a new array keep only items that match condition. 

3) What are arrow functions in ES6?
Solution:
arrow function is shorter way to write function in ES6. It used => instead of function keyword. 
const add = (a,b) => a+b;

4) How does destructuring assignment work in ES6?
Solution:
